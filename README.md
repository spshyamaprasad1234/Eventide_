# Eventide_
A responsive and interactive web application designed to help users seamlessly plan, promote, and manage events such as weddings, corporate summits, private parties, and entertainment shows. This platform brings together vibrant design and essential functionality to enhance the event planning experience.
✨ Features
🎉 Event Highlights with interactive image sliders and circular gallery

📝 Client Testimonials with elegant animations and hover effects

📰 Blog Section to share event planning tips and updates

📩 Contact Form with PHP backend support (XAMPP-compatible) to receive queries via email

⬆️ Scroll to Top Button with beautiful design and smooth behavior

💡 Modern design with hover animations, gradients, and responsive layout

🛠️ Built With
HTML5, CSS3, JavaScript

PHP (for form handling via XAMPP)

CSS animations & keyframes

Responsive design techniques

📦 How to Use
Clone or download the repo

Open with any local server (e.g., XAMPP for PHP support)

Configure the contact form with your email

Explore the sections and customize as needed!
